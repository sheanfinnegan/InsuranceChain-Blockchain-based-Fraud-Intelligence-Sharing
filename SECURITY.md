# Pelaporan keamanan

Jangan membuka issue publik yang memuat kredensial, private key, data identitas, evidence, atau langkah eksploitasi terhadap instalasi aktif.

Jika tersedia, gunakan **Security → Report a vulnerability** pada repository GitHub untuk melapor secara privat. Jika fitur tersebut belum diaktifkan, hubungi pemilik melalui profil GitHub untuk menyepakati kanal privat sebelum mengirim detail sensitif.

Sertakan komponen yang terdampak, commit yang diuji, dampak, dan langkah reproduksi menggunakan data buatan. Proyek penelitian ini belum memiliki SLA penanganan atau jaminan dukungan versi tertentu.

Konfigurasi lokal, volume, ledger, dan sertifikat tidak disertakan dalam Git. Akun awal pengembangan harus diganti sebelum instalasi dipakai di luar lingkungan lokal. Lihat [batas implementasi](docs/architecture.md#batas-implementasi-saat-ini).
