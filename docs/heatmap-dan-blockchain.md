# Heatmap, identifiers, dan observabilitas

Kasus baru wajib menyertakan provinsi dan kabupaten/kota **tempat kejadian**. API dan chaincode menolak lokasi yang tidak lengkap. Lokasi kasus lama tidak ditebak: kasus tersebut masuk kategori `Lokasi belum dilengkapi`. Identifier mendukung 1–20 baris, dapat ditambah atau dihapus, dan API menolak duplikasi jenis/nilai. Ledger hanya menerima hash dan nilai yang disamarkan.

Peta menampilkan titik agregasi 38 provinsi, bukan batas administrasi per provinsi atau alamat kejadian. Warna dan ukuran halo mengikuti jumlah kasus pada cakupan yang dipilih: semua laporan atau hanya approved. Klik titik, daftar peringkat, atau pilihan provinsi membuka pencarian dengan filter provinsi dan status yang sama. URL menyimpan filter sehingga dapat dimuat ulang. Banyaknya laporan bukan ukuran risiko per kapita.

Garis pantai berasal dari dataset public-domain [Natural Earth 1:50m countries](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson); geometry Indonesia disimpan lokal di `public/maps/indonesia.json`. Titik provinsi adalah perkiraan titik representatif untuk visualisasi, bukan hasil geocoding kasus. ID provinsi merupakan identifier internal aplikasi. Font Poppins di-host lokal dari paket Fontsource (lisensi OFL). Ilustrasi jaringan pada login adalah SVG animasi dekoratif, ditandai sebagai ilustrasi, dan menghormati preferensi reduced motion.

Claim Staff hanya memiliki dashboard dan pencarian/detail kasus. Navigasi langsung ke voting, history, pengelolaan anggota, dan aktivitas blockchain diarahkan ke dashboard. Pengaturan akun dan logout dapat diakses dari menu profil. API mutasi analis/OJK serta API log blockchain tetap memeriksa peran secara independen.

Halaman **Aktivitas blockchain** tersedia bagi analis dan OJK, diperbarui setiap 3 detik dan dapat dijeda. Log persist di PostgreSQL mencatat proposal, endorsement, penerimaan submit, serta hasil commit dari Fabric Gateway. Transaction ID, nomor blok, dan validation code berasal dari SDK. Query/evaluate dicatat terpisah dan tidak diklaim membuat blok. Waktu setiap tahap adalah saat aplikasi mengamati respons, bukan timestamp internal setiap peer. Hasil submit yang tidak dapat dikonfirmasi ditandai UNKNOWN, bukan otomatis gagal atau berhasil. Log bukan pemantauan semua trafik jaringan. Riwayat sebelum instrumentasi tersedia sebagai event pada detail kasus, bukan dibuat ulang dengan waktu tahap fiktif.

Konsorsium diperluas menjadi Nusantara Assurance, Sentra Life, Arunika Insurance, Cakrawala Proteksi, dan Pradana Life. Org4/Org5 memiliki MSP, peer, dan CouchDB mandiri. Aturan voting bisnis tetap `ceil(2*N/3)` termasuk dukungan pengaju; lima organisasi memerlukan empat dukungan. Snapshot putaran lama tidak berubah. Endorsement teknis channel tetap dua dari tiga peer pendiri; ini berbeda dari voting bisnis lima organisasi.
